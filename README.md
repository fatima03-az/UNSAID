# Unsaid

An intelligent personal assistant that turns thoughts into organized tasks.

## Description
Unsaid is an Android application that lets users write or speak their thoughts naturally, without organizing them first. The app reads the text and automatically extracts tasks, events, and notes, along with categories, priorities, and deadlines. The user reviews the results and approves them before anything is saved.

The idea is simple: people shouldn't have to organize their thoughts before entering them into an app. They express themselves, and the app does the organizing.

## Planned Features
- Smart thought capture (typing or voice input)
- Automatic extraction of tasks, events, and notes
- Automatic categorization and priority setting
- Deadline detection from sentences like "next Monday"
- Review screen: AI suggests, the user approves
- Task dashboard, history, and search
- Reminder notifications
- Offline-first: works without internet, with cloud AI used when available

## Technologies
- Java and XML (Android Studio)
- Room database (local storage)
- Gemini API (AI processing) with a rule-based backup parser
- Material Design 3 with a custom dark "Dusty Rose" theme
